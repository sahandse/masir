# مسیر در برابر Waze رایگان

هدف: مسیریاب فارسی رایگان با حس Waze روی دادهٔ باز — بدون Google پولی، بدون دادهٔ جعلی، بدون کپی برند Waze.

## انجام‌شده
- مسیریابی زنده GPS + HUD + صدا فارسی
- مسیر جایگزین واقعی
- خانه / کار / علاقه‌مندی
- گزارش جامعه (محلی + backend خودمیزبان در `server/`)
- هشدار رویداد روی کریدور مسیر + مسیر جایگزین
- صفحه شروع ساده (سرچ بزرگ)
- پرهیز Valhalla از نقاط گزارش واقعی ترافیک/بسته/تصادف
- MapLibre + دانلود آفلاین منطقه اطراف
- APK رایگان بدون حساب/تبلیغ در ناوبری

## عمداً انجام نمی‌شود
- Google Maps به‌عنوان هسته
- ترافیک/ETA/مسیر Demo یا جعلی
- کپی ظاهر برند Waze

## بهبودهای بعدی (اختیاری)
- مقیاس‌دهی backend گزارش (Redis/Postgres)
- پوشش آفلاین شهرهای ازپیش‌آماده
- منبع ترافیک خودمیزبان جدا از گزارش کاربران، اگر در دسترس باشد
