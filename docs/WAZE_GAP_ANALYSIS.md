# مسیر در برابر Waze رایگان

هدف محصول: مسیریاب فارسی رایگان با حس Waze، روی دادهٔ باز (OSM) و بدون قفل پولی یا وابستگی اجباری به Google Maps.

## الان چه چیزی شبیه Waze است
- مسیریابی زنده با GPS + چرخش نقشه + زوم خودکار
- راهنمای صوتی فارسی و بنر مانور
- مسیرهای جایگزین واقعی + انتخاب روی نقشه
- توقف‌های بین راه
- خانه / محل کار / علاقه‌مندی / تاریخچه (فقط دادهٔ کاربر)
- گزارش رویداد (ترافیک، تصادف، پلیس، بسته، خطر، عملیات)
- هشدار سرعت و دوربین سرعت از OSM
- POI اطراف از Overpass
- بدون Mock/Demo Location در UI

## رایگان بودن چطور تضمین می‌شود
| لایه | منبع | هزینه کاربر |
|---|---|---|
| نقشه | OpenStreetMap tiles | رایگان |
| جستجو | Nominatim | رایگان |
| مسیر | Valhalla (`VALHALLA_BASE_URL`) | رایگان برای کاربر نهایی |
| POI / maxspeed | Overpass | رایگان |
| گزارش | ذخیره محلی (+ سرور اختیاری) | رایگان |

Google Maps Platform عمداً منبع اصلی نیست تا اپ بعد از سقف رایگان به Pay-as-you-go وابسته نشود.

## شکاف‌های باقی‌مانده تا «Waze کامل»
1. **ترافیک زندهٔ سراسری** — نیاز به منبع معتبر رایگان/خودمیزبان (فعلاً فقط گزارش کاربران و reroute محلی)
2. **جامعهٔ چندکاربرهٔ زنده** — `REPORT_API_BASE_URL` + backend برای اشتراک گزارش‌ها بین دستگاه‌ها
3. **نقشهٔ برداری آفلاین** — MapLibre + offline regions
4. **پلیس/دوربین با دقت جامعهٔ بزرگ** — وابسته به حجم گزارش واقعی کاربران
5. **حساب کاربری اختیاری** — همگام‌سازی خانه/کار بین دستگاه‌ها

## اصل محصول
هر چیزی که کاربر می‌بیند باید واقعی باشد. گزارش‌های ساختگی، ترافیک جعلی یا مسیر نمونه در UI نمایش داده نمی‌شود.
